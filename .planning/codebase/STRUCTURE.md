# STRUCTURE.md

## Directory Layout
- `Auction-Project/` (Frontend)
  - `src/` - React components, pages, hooks, and services
  - `public/` - Static assets
  - `docs/` - Frontend documentation
- `Auction-Server/` (Backend)
  - `src/` - Server controllers, models, routes, and utilities
  - `server.js` - Main Express/Socket.IO entry point
- `hoco/` - (Unidentified project files)
- `PRD.md` - Product Requirements Document

## Key Locations
- `Auction-Project/package.json` - Frontend build commands & dependencies
- `Auction-Server/package.json` - Backend start commands & dependencies
- `Auction-Server/server.js` - Application initialization

## Naming Conventions
- React components: PascalCase (implied)
- Backend routes/controllers: camelCase (implied)
