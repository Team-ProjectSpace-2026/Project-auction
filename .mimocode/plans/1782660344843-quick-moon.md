# Fix CodeQL Config & Security Vulnerabilities

## Problem 1: CodeQL Config Invalid
The error `Cannot deserialize value of type java.lang.String from Object value` means the `queries` format is wrong. The current config has:
```yaml
queries:
  - uses: security-and-quality
```
CodeQL expects `queries` to be a list of objects with `uses` as a path reference, not a bare string.

**Fix**: Remove the `queries` section entirely (use default queries) OR use the correct format.

## Problem 2: 4 High Severity Security Alerts
"Database query built from user-controlled sources" - CodeQL flags `req.body` values flowing into MongoDB queries.

| File | Line | Query |
|------|------|-------|
| `auth.controller.js` | 57 | `User.findOne({ email })` |
| `player.controller.js` | 56 | `Player.findByIdAndUpdate()` |
| `team.controller.js` | 59 | `Team.findByIdAndUpdate()` |
| `tournament.controller.js` | 53 | `Tournament.findByIdAndUpdate()` |

**Fix**: Add explicit validation/sanitization wrappers before each query to break the taint flow.
