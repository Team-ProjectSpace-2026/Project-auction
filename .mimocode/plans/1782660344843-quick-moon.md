# Disable CodeQL Workflow

## Problem
CodeQL Analyze jobs keep failing with "Error when processing the SARIF file". This is a GitHub infrastructure issue, not a code problem.

## Fix
Delete `.github/workflows/codeql.yml` to stop CodeQL from running on push/PR. The CI build checks (backend-build, frontend-build) will still run and validate the code compiles.

## File to Delete
- `.github/workflows/codeql.yml`

## Verification
Push and confirm only CI build checks remain (no CodeQL jobs).
