# Fix CodeQL Config Parse Error

## Problem
Two remaining CI failures: `CodeQL / Analyze` crashes with "Config file supplied is not valid" and `paths.join is not a function`.

The security alerts are already resolved ("No new alerts in code changed by this pull request").

## Root Cause
The `.github/codeql-config.yml` uses nested `include`/`exclude` objects under `paths`, but CodeQL expects `paths` to be a flat string array.

## Fix (2 changes)
1. **Delete** `.github/codeql-config.yml` entirely — no config needed
2. **Edit** `.github/workflows/codeql.yml` — remove the `config-file:` line (line 33)

After this, CodeQL uses its built-in defaults and no config file is parsed.

## Verification
Push and confirm both `CodeQL / Analyze` jobs pass.
